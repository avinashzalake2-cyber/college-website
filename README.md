# 🎓 College Website Project (Hosted on AWS & GitHub)

## 🚀 Project Overview
This is a responsive College Website developed using HTML and CSS.  
The project is deployed using cloud services and version control for real-world experience.

## ☁️ Cloud Deployment
The website is hosted using **Amazon Web Services (AWS) S3 Static Website Hosting**, which provides scalable and reliable cloud storage for static web applications.

## 🛠️ Technologies Used
- HTML5
- CSS3
- Git & GitHub
- Amazon Web Services (AWS S3)

## 🌐 Live Hosting Platforms
- AWS S3 Static Website Hosting
- GitHub Pages (for version control and deployment)

## 📌 Features
- Responsive UI design
- Attractive navigation bar
- Course information section
- About college details
- Contact section
- Hover animations and modern layout

## 🎯 Purpose of Project
The main goal of this project is to understand:
- Cloud computing basics
- Static website hosting on AWS
- Git & GitHub version control
- Real-world deployment workflow

## 📷 Output
This project successfully demonstrates deployment of a static website on cloud infrastructure using AWS services.
